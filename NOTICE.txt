Thrum — third-party notices

Thrum is licensed under the GNU General Public License, version 3 or later

This file documents third-party material that Thrum redistributes, vendors,
or requires. Every entry below was verified on 2026-07-31 against the actual
distributed artifact — the licence file inside each NuGet package, the licence
text in each vendored source tree, or the upstream project's own licence — not
against secondary sources. The method and the evidence are recorded in
docs/dev/third-party-audit.md.

Two items remain without a clean licence grant. They are listed in
the UNRESOLVED section at the end of this file and are release-blocking. Do not
publish a binary release while that section is non-empty without a deliberate,
recorded decision about each item.

As of 2026-08-03 both carry a decision taken for the 0.9.0-beta.1 release and
written into their entries below: item 1 ships with a licence request
outstanding, and item 2 ships with reasons stated. Recorded is not the same as
resolved — every item stays listed until it is genuinely resolved, and a later
release must re-examine each one rather than inherit these decisions by default.

Two files in the tree carry their own notices and are authoritative for what
they cover; this file does not restate them:

    DS4Windows/ThirdParty/SbcSharp/LICENSE.txt and NOTICE.md

4. External components Thrum requires but does NOT redistribute
--------------------------------------------------------------------------------

These are downloaded or installed by the user on their own machine. No copy of
any of them is contained in this repository or in a Thrum release package.

    VIIPER — GPL-3.0 — https://github.com/hbashton/VIIPER
        The virtual-controller backend. Thrum downloads a pinned release binary
        and runs it as a separate process, communicating over a local socket.
        It is not linked into Thrum and no part of it is redistributed here.

    usbip-win2 — BSD-2-Clause — https://github.com/vadimgrn/usbip-win2
        Kernel USB/IP driver. Installed by the user from the upstream signed
        installer, which Thrum verifies by digest and Authenticode before
        running. Not redistributed.

    HidHide — https://github.com/nefarius/HidHide
        Optional device-hiding filter driver, installed by the user from its own
        official installer. Not redistributed.

UNRESOLVED — release-blocking
================================================================================

1. FakerInputWrapper.dll has no licence grant.

   https://github.com/Ryochan7/FakerInputWrapper contains no LICENSE file, no
   per-file licence headers, no licence metadata in its .csproj, and an empty
   README (checked 2026-07-31). The assembly is authored by "Ryodigi Solutions
   LLC". Thrum redistributes this binary in every release package.

   Absent a grant, default copyright reserves all rights, so there is no
   permission to redistribute it. Options: ask the author to add a licence;
   drop the dependency; or replace it. The related native FakerInputDll.dll,
   from Ryochan7/FakerInput, IS MIT-licensed — only the .NET wrapper is
   affected. Inherited from upstream DS4Windows, not introduced by Thrum.

   MAINTAINER DECISION (2026-08-03): the 0.9.0-beta.1 release ships this
   assembly while the grant is outstanding. A licence request has been filed
   with the author (Ryochan7/FakerInputWrapper issue #1) asking for MIT, to
   match the native FakerInput project. If no grant is forthcoming, the
   fallback is to remove the dependency: FakerInput is the *optional* keyboard
   and mouse output handler — SendInput is the default and is what the
   validation passes ran on — and its used surface measures at roughly ten
   P/Invoke members, so a clean-room wrapper over the MIT-licensed
   FakerInputDll.dll is small. This item stays open until there is a grant or
   that replacement ships. Anyone redistributing this release should be aware
   the wrapper's terms are unresolved.

2. Two vendored items cannot be fully enumerated or licensed.

   a) DS4Windows/OneEuroFilter.cs carries no licence header. The 1€ filter
      authors' own page lists the C# implementation under "other implementations
      not verified yet" with no licence stated, while their Python, C++, Java,
      JavaScript, TypeScript and Arduino versions are BSD or MIT
      (https://gery.casiez.net/1euro/). The algorithm is published research
      (Casiez, Roussel, Vogel, CHI 2012); the specific C# port's terms are
      unknown. 105 lines. Cheapest resolution is to reimplement from the paper
      or port from a BSD-licensed reference version.

   b) DS4Windows/BezierCurveEditor/build.js is a 431 KB minified webpack bundle.
      The top-level project is MIT, but the bundle embeds npm dependencies whose
      individual notices are not recoverable from the minified artifact. If the
      editor is still wanted, rebuild it from source so a dependency licence
      manifest can be generated; if it is not, delete it. It is a vendored web
      asset with no other role in the application.

   MAINTAINER DECISION (2026-08-03) for both (a) and (b): the 0.9.0-beta.1
   release ships them as-is, for these stated reasons rather than by oversight.

   (a) The 1€ filter is published research (Casiez, Roussel, Vogel, CHI 2012)
       and its authors publish their own ports under BSD or MIT; only this C#
       port lacks a stated licence, and it is 105 lines implementing a
       documented algorithm. Planned resolution is reimplementation from the
       paper so the file carries a Thrum GPL-3.0 header outright.

   (b) The Bezier editor bundle's top-level project is MIT and its embedded npm
       dependencies are the usual MIT/ISC web set; what is missing is a
       per-dependency manifest, not a permissive grant. Planned resolution is to
       rebuild from source so the manifest can be generated, or to delete the
       editor if it is not wanted.

   Both are inherited from upstream DS4Windows and neither is believed to be
   non-permissive. They remain listed here — a planned resolution is not a
   resolution — and this notice is the record that shipping them was deliberate.
